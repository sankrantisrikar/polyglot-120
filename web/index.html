How it works

One request, two models, one honest answer.

1
Primary modelXLM-R fine-tuned on 120 languages scores the text and returns a softmax over all labels.
2
Confidence checkIf the top probability is below the threshold, the request is marked uncertain instead of returning a shaky guess.
3
Fallback routeUncertain inputs go to fastText lid.176, a lighter model that is more robust on very short or noisy text. The response says which path answered.
